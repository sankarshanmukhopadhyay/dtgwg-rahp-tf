# RAHP Toolkit v0.4.0

**Release theme:** from repeatable pressure testing to governed, observable assurance.

v0.4.0 retains the v0.3 machine-readable method and adds the first bounded operational
governance layer. It also consolidates the scenario-corpus, security, combined-review,
GitHub Pages, Historical Library, corpus-provenance, and AI-agent capabilities developed
since the v0.3 draft.

## Highlights

- **Operational assurance pilot:** five metrics now carry proposed monitoring contracts
  covering signals, threshold rules, triage workflow, responsible roles, evidence, SLAs,
  appeals pathways, and revocation triggers.
- **Evidence artefacts:** `EV-*` records make evidence provenance, collection, retention,
  sensitivity, and metric linkage first-class.
- **Governance rule profile:** `RP-001` makes the proposed Q3/Q4 risk-acceptance model
  machine-readable while remaining explicitly unratified.
- **Normative triage workbench:** build-time candidate classifications help reviewers
  progress the unassigned control/guardrail backlog without auto-assigning standards status.
- **Agent governance primitives:** a portable three-class non-human actor taxonomy and
  JSON Schema for bounded delegation scope, with a validated example.
- **Scenario-driven assurance:** four source/composed corpora provide 74 scenarios mapped
  to portable RAHP scenario patterns.
- **Selectable review lenses:** RAHP, security-hardening, and combined review modes share
  one orchestration entry point.
- **Corpus provenance and drift:** related repositories are tracked as curated source
  dependencies with review-aware drift status.
- **Reader-first documentation:** Just the Docs/GitHub Pages covers canonical structured
  data, worked examples, diagrams, AI-agent workflows, and the Historical Library.

## Compatibility

The canonical v0.3 DTG records remain valid. v0.4 adds two new record namespaces:

- `RP-*` — governance rule profiles;
- `EV-*` — evidence artefacts.

Portable method additions include `method/non-human-actors.yaml` and
`method/schema/delegation-scope.schema.json`.

Existing worked reviews retain the RAHP version recorded when they were performed
(`v0.3-dev`). New reviews should record `v0.4.0`.

## Governance caveat

`RP-001` and all five monitoring contracts are `proposed`/`pilot_proposed`. The release
ships the **machine-readable mechanism and worked operating profile**, not a claim that
DTGWG has ratified those governance decisions or deployed those monitoring controls.
