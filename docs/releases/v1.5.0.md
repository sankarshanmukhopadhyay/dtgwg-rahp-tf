# RAHP Toolkit v1.5.0 — Purple Leaf Blue

**Scientific name:** *Amblypodia anita*  
**Release family:** Continuous Governed Assurance  
**Compatibility:** additive v1.x release

v1.5.0 advances RAHP from evidence-driven point-in-time assurance to **Continuous Governed Assurance** while preserving the stable v1 compatibility boundary and deployment independence.

## Added

- durable assessment and finding lineage independent of issue trackers and individual runs;
- governed remediation obligations, acceptance criteria, closure evidence and executable retest lineage;
- portable assurance graph and deterministic change-impact selection;
- evidence provenance, conservative assurance freshness and machine-readable assurance delta;
- executable scoped authority with suspension, revocation and expiry semantics;
- portable policy gates with `PASS`, `FAIL` and `INDETERMINATE` outcomes;
- operational assurance posture without a synthetic universal assurance score;
- registry-driven implementation/documentation synchronization;
- a machine-verifiable v1.5 release qualification contract.

## Continuous governed assurance lifecycle

```text
material target change
        ↓
impact selection
        ↓
freshness evaluation
        ↓
evidence retained / weakened / invalidated
        ↓
assessment or retest
        ↓
assurance delta
        ↓
residual obligation + remediation
        ↓
policy gate: PASS | FAIL | INDETERMINATE
        ↓
independent authority verification
        ↓
governed disposition / publication
        ↓
portable assurance posture
```

## Governance properties

- observation does not confer assessment authority;
- assessment does not confer publication authority;
- policy-gate `PASS` does not create delegation;
- detector absence does not prove remediation closure;
- issue/work-item state is not canonical assurance identity;
- risk acceptance and closure remain separately authorized actions.

## Portability

Portable RAHP schemas and engine contracts remain independent of DTG, OpenVTC, ARPA, CAWG/C2PA, GitHub, or any other maintained deployment. Project-specific examples demonstrate adoption and stress the portable abstractions; they do not define the core method.

## Compatibility

The stable v1 boundaries remain:

```text
rahp-engine-contract-v1
normalized result schema version 1
rahp-evidence-retention-v1
```

v1.5.0 is additive within that compatibility boundary. Existing v1.1 and v1.2 normalized results remain valid.

## Qualification evidence

The release is qualified by `method/v1.5-release-qualification.yaml` and `tools/validate_v15_release.py`, together with the repository-wide validation and documentation build workflows. Qualification covers portable conformance fixtures, documentation synchronization, stable release metadata, Python/TypeScript conformance, generated-evidence freshness, reference links, maintained deployment demonstrations, and rendered Pages coverage.

## Release naming

From v1.5.x onward, RAHP releases use a randomly selected butterfly from the recorded West Bengal butterfly list as human-readable release metadata. This release is **Purple Leaf Blue — *Amblypodia anita***. Semantic version `v1.5.0` remains the compatibility authority.
