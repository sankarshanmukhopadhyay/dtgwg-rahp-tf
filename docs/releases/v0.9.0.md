# v0.9.0 — TypeScript Reference SDK

v0.9.0 proves that the language-neutral execution boundary introduced in v0.8 can be implemented independently of the Python reference adapter.

## Highlights

- Adds dependency-free runtime packages `@rahp/schema`, `@rahp/core`, `@rahp/graph` and `@rahp/cli`.
- Implements normalized-result validation and v0.8 evidence-retention decisions in TypeScript.
- Loads and enumerates RAHP deployment profiles without invoking Python.
- Projects `build/rahp.json` into a graph for identifier tracing and relationship inspection.
- Runs the same engine conformance fixtures as Python.
- Adds a differential validator requiring Python and TypeScript to agree on fixture validity and retention plans.
- Wires TypeScript build/conformance into CI while leaving existing operational monitoring and issue publication unchanged.

## Compatibility

`rahp-engine-contract-v1`, `rahp-result.schema.json` and `rahp-evidence-retention-v1` are unchanged. v0.9 is therefore an implementation-portability release, not a method-semantics migration. Existing v0.8 review revalidation metadata remains historically correct.

## Acceptance evidence

The release is accepted only when the shared Python/TypeScript conformance gate passes, the portable-project profile validates, the catalogue graph projection is non-trivial, and the existing Python validation/build suite remains green.
