# RAHP Toolkit v0.4.0 release notes

The canonical reader-facing release notes are maintained at
[`docs/releases/v0.4.0.md`](docs/releases/v0.4.0.md).

v0.4.0 advances RAHP from machine-readable pressure testing to the first bounded
operational-assurance layer: proposed rule profiles, evidence artefacts, five pilot
monitoring contracts, deterministic normative-triage support, portable non-human actor
classification and delegation-scope validation, and runtime triage
documentation. It also closes the 31 asymmetric links and three orphan-control
consistency gaps carried forward from the v0.3 migration.

**Recommended Git tag:** `v0.4.0`
