**Attack / failure path**

An intermediary removes CAWG identity, consent or endorsement assertions but leaves a lower-layer C2PA manifest that validates.

**Existing mitigations**

- Cryptographic integrity and signature validation constrain direct content tampering but do not close this higher-layer failure path.

**Residual gap**

Without a deployment expectation profile, absence is not cryptographic proof of stripping and may be accepted as normal.

**Recommended hardening**

Introduce relying-party profiles declaring required assertion classes and a downgrade/expected-evidence-missing result.

**Verification / closure evidence**

- Add a negative interoperability vector reproducing the failure and require a distinct non-success validation result.
