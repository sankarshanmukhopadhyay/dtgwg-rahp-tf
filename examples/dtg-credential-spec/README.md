# DTG Credential Specification pressure-test example

This directory demonstrates how to package a RAHP review so that a standards author can reproduce the scope, trace findings to RAHP artefacts, and follow disposition to a standards/governance action.

The sample record in `pressure-test.yaml` uses the record shape proposed for RAHP adoption. It is deliberately marked **illustrative**: its purpose in this commit is to make the workflow executable and understandable, not to introduce new adjudicated findings into the canonical DTG dataset.

For a substantive review, replace the target version/commit, document affected personas/scenarios, link each finding to canonical risks/controls/guardrails, attach evidence, and update status when a specification revision or PR resolves the finding.
