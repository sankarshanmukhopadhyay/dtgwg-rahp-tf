What this site enables you to do

The DTG Risk & Harm Prevention framework maps every risk, metric, persona, user story, scenario, and EPIC into a single navigable reference. It is designed to answer three questions that arise during standards development:

Start from a person Pick any persona below to see which risks threaten them, which metrics signal those risks, and which user stories and scenarios they appear in.
Navigate by item Use the Cross-Reference Matrix to find every User Story, Scenario, or EPIC linked to a given metric — or scan across a row to see all metrics an item triggers.
Assess risk and control coverage The Risks & Metrics page lists all 35 risks with severity, likelihood, a sortable risk score, and the metrics that would detect or measure each risk. Hover any ID for an instant description.

Hover any coloured ID pill (M-01, US-03, RK-AI04…) on any page for a tooltip description. Click a persona card to open the full detail panel.
