# Historical artefacts

Historical artefacts are retained for provenance and migration history. **Do not edit them as current RAHP sources.**

Current canonical RAHP instance data is maintained under `data/`. Portable method definitions are under `method/`. Generated outputs belong under `build/`.

The spreadsheets/documents retained here are the historical files present in this fork archive. Some canonical YAML records record provenance from later source versions that were not included in the supplied archive; those provenance claims have been preserved rather than rewritten.
