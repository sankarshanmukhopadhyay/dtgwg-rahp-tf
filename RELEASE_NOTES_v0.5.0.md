# RAHP v0.5.0 release notes

v0.5.0 makes RAHP configuration-driven and operationally portable. A Working Group, developer, or reviewer can checkout RAHP, provide one YAML profile listing one or more target repositories, and scaffold RAHP, security, or combined reviews without inheriting DTG-specific corpora, issues, governance records, or portfolio-monitor metadata.

See [`docs/releases/v0.5.0.md`](docs/releases/v0.5.0.md) for the full release notes.
